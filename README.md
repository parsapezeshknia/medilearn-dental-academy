# MediLearn — Dental Medicine & Anatomy Academy\n\nEnglish-language educational website for dental students.\n\n## Features\n- Six modules: skull anatomy, oral cavity, tooth morphology, periodontium, oral histology, and trigeminal nerve foundations.\n- Lesson objectives and structured explanations.\n- Five-question quiz with score and explanations.\n- Browser localStorage progress tracking.\n- Prepared-response study helper (not a live AI model).\n- Responsive professional blue-and-white design.\n\n## Run locally\n```bash\npip install -r requirements.txt\npython app.py\n```\nOpen http://127.0.0.1:5000\n\n## Render settings\nBuild: `pip install -r requirements.txt`\nStart: `gunicorn app:app`\nHealth check: `/health`\nSet a `SECRET_KEY` environment variable.\n\nEducational content only; not a substitute for textbooks, clinical supervision, or professional medical advice.\n
